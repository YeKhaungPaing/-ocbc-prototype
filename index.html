Agent 3 · Credit intelligence Checking AI status…

COMPASS

Checks the credit bureau first. If there's healthy history, it rewards the behaviour. If the file is thin (new expats, students, freelancers), it asks permission to view specific transaction categories instead.

Guardrails

Scoped, permissioned access

  • Bureau check happens first, always.
  • Thin-file customers are never auto-declined — COMPASS asks first.
  • Permission is scoped to named categories only (e.g. entertainment, utilities), never full transaction history.
  • Decision reasoning is logged and explainable, not a black box.
  • A decline always comes with a concrete path to reapply.
